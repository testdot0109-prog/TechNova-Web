# Tech Nova onboarding

A frontend-only three-stage account and competency onboarding flow.

## Run it

```bash
npm install
npm start
```

Open `http://localhost:3000` when the development server is ready.

The flow stores the in-progress account, profile and selected level in browser local storage. The Google button and learning-plan button are intentionally visual placeholders: they do not make sign-in, backend, or API requests.
